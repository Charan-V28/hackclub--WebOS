# 💻 My WebOS

A personal, interactive web-based operating system simulated directly in the browser! Built step-by-step following the [Hack Club WebOS Jam](https://jams.hackclub.com/batch/webOS).

---

## ✨ Features

- **Welcome Screen:** Intro landing card with a smooth fade transition into the desktop workspace.
- **Desktop Environment:** Custom background, top bar with an active status badge, and desktop app icons.
- **Live Clock:** Real-time updating clock displayed on the top right bar.
- **Interactive Windows:** Open, close, and drag windows anywhere across your browser screen.
- **Built-in Apps:**
  - 📝 **Notes / Personal Profile:** Multi-tab interactive view featuring "About Me", "My Skills", and "Stardance Goals".
  - 📂 **Projects App:** Showcase of current work and builds.
  - 🧮 **Calculator:** Fully functional browser calculator app.

---

## 🛠️ Built With

- **HTML5** — Semantic layout & structural components
- **CSS3** — Custom glassmorphism design, flexbox grid, animations & styling
- **JavaScript (Vanilla)** — Live clock updates, window DOM management, drag-and-drop mechanics, and app state logic
